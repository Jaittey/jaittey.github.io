BEFORE UPLOADING HTML v4.1
==========================

Delete these old React/Vite items from the GitHub repository if they still exist:

- src/
- dist/
- node_modules/
- package.json
- package-lock.json
- vite.config.js
- any old workflow under .github/workflows/ that runs:
  - setup-node
  - npm install
  - npm ci
  - npm run build
  - vite build

Keep only the new workflow:

.github/workflows/deploy-pages.yml

The HTML v4.1 application is deployed directly and does not require npm.
