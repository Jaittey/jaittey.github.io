# DF7 Logo, Invoice Customer Fields, Quotation Dates and Mobile Update

## Included
- New company logo and icon
- Invoice Bill To: Name, Contact Number, Customer Address
- Customer selection automatically fills phone and address
- Quotation Date and Expire Date use the same `DD Mon YYYY` format
- Mobile-optimised forms, tables, buttons and modals
- Updated service-worker cache

## Deploy
1. Replace all repository files with this package.
2. Keep GitHub Actions secrets unchanged.
3. Make sure `.github/workflows/deploy-pages.yml` exists.
4. Commit to `main`.
5. Wait for the GitHub Pages workflow to turn green.
6. Clear the old site cache or use a private tab.
